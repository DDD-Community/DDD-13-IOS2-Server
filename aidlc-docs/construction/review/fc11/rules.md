# 비즈니스 규칙 — FC-11 투표 생성 + 마감일

## 마감일
- 프리셋: 투표 시작 기준 **+1 / +3 / +7일**, 마감 시각 선택일 **23:59:59**
- 자동 전환(전원 담기/마감/호스트)으로 시작 시 기본 **+3일**

## 유효성
- 투표 마감일 < **약속 날짜(모임일)**
- 투표 마감일 > 투표 시작일
- 위반 시 PLACE_VOTE_DEADLINE_INVALID(400) — "투표 마감일은 약속 날짜 이전으로 설정해 주세요"
