# 비즈니스 규칙 — FC-9 장소 후보 탐색 + 담기

## 조회/표시
- 역 탭: 역 선택 시 **그 역에 귀속된 추천 장소만** 노출
- 카테고리 필터 + 예약/주차 필터(이동해도 유지). 데이터 없는 카테고리 미노출
- 정렬: 추천 스코어 내림차순
- 카드: 상호명, 카테고리, 도로명주소, 분위기태그(≤3), **카드거리(보는 사람 출발지 기준)**, 함께담기 수

## 카드 거리 정의
- = 보는 사람 출발지 최근접역 → 장소 최근접역 **그래프 최단경로** 값 (FC-12 그래프 재사용)
- 단일출발 다익스트라 1회로 전역 계산

## 담기 정의
- 한 모임원이 **1개 이상 담으면 담기완료**(프로필 체크). 별도 완료버튼 없음
- 담기/취소 자유. **후보 0개 되면 미완료**로 복귀
- 마감 후 담기 시도 → PLACE_PICK_CLOSED(400)

## 인가 (담기·취소·조회)
- 대상은 **그룹원이 아니라 해당 모임의 참여자(`meeting_participant`)**. 그룹에 속해도 이 모임 참여자가 아니면 거부 → 403 MEETING_024 (NOT_MEETING_PARTICIPANT)
  - 새 모임은 호스트가 그룹원 중 일부만 참여자로 선택할 수 있으므로 "그룹원 ≠ 모임 참여자"가 정상적으로 존재한다.
- **담기/취소(쓰기)는 활성 참여자(JOIN/LATE)만 가능.** `ABSENT`(불참) 참여자는 거부 → 403 MEETING_025 (ABSENT_PARTICIPANT_CANNOT_ACT)
  - 완료 판정 분모가 활성 참여자(ABSENT 제외)이므로, 불참자가 담기하면 집계·판정이 어긋나기 때문. 참석여부는 장소 단계 진입 시 잠기므로(FC-7-1) 담기 중 분모는 고정.
- 조회(목록/현황)는 참여자면 상태 무관하게 허용.

## VOTING 전환 조건 (하나라도 충족 시 즉시)
1. 전원 담기완료
2. 담기 마감(날짜확정 +3일 23:59:59) 도래 — 스케줄러
3. 호스트 '투표 생성하기'(후보 ≥ 1)

## 마감 시 후보 0개 (아무도 안 담음)
- 추천 **스코어 상위 3개 자동 후보 등록** 후 VOTING 전환
