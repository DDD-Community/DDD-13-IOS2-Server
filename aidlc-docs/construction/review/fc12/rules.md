# 비즈니스 규칙 — FC-12 장소 투표 진행

> 2026-06-24 갱신 (mvp3-1 갭 보완). 변경점은 ⭐ 표기.

## 투표 후보 정의 ⭐
- 투표 후보 = **담긴 장소(`meeting_place_pick`)** 기준. (추천 15개 `meeting_place_recommendation` 아님 — 기존 오구현 수정)
- 현황 조회·투표 제출·이동부담 계산 모두 동일하게 담긴 장소 집합 사용.

## 후보 최소 3개 백필 ⭐
- 투표 시작 시점(호스트 수동 / 전원 담기 / 마감 자동 — 모든 경로) 담긴 후보 distinct < 3 이면,
  **추천을 rank 오름차순으로, 이미 담긴 장소 제외하고 3개가 될 때까지 시스템이 자동 담기**.
- 추천 총량이 3 미만이면 가능한 만큼만.
- 백필 행: `meeting_place_pick`에 `source='SYSTEM'`, `member_id=NULL` 로 적재. 일반 후보와 동일 취급(투표·확정 대상).
- 담기 0개여도 정상 투표·확정 진행(기존 0개 멈춤 버그 해소).

## 정렬 ⭐
- 투표 전(내 투표 0): 상호명 가나다순 / 투표 후: 득표수 높은 순

## 다중 제한 ⭐
- 1인 최대 = **담긴 후보 수의 50% 내림**, 단 **최소 1** (후보6→3, 후보3→1)
- 초과 시 PLACE_VOTE_LIMIT_EXCEEDED(400)

## 제출 검증 ⭐
- 제출 placeId 전부가 **현재 후보 집합(담김+백필)** 에 속해야 함. 위반 시 PLACE_VOTE_INVALID_CANDIDATE(400)

## 완료 정의
- 1개 이상 투표 시 **투표완료**. 마감 전 추가/취소 자유. 0개 되면 미완료

## 익명성 + 멤버별 참여현황 (전원 공개) ⭐
> 🔄 2026-06-24 변경: 호스트 전용 → **모든 구성원 공개**.
- member_id 저장하되 **누가 어디에 투표했는지(투표 대상)는 전원 비공개**.
- **모든 호출자**(호스트/구성원 무관) 조회 시: 구성원별 **완료/미완료 여부** 리스트(`memberStatuses[]`) 제공.
- 공개 범위는 "완료/미완료"에 한정 — 어떤 후보에 투표했는지는 누구에게도 비공개.
- 리스트 기준 집합 = 모임 활성 참여자(ABSENT 제외), 이름은 닉네임.
- 총 참여율(N/N)도 함께 제공.

## 이동 부담 (subway_edge 그래프)
- 참여자별 **단일출발 다익스트라** 1회 → 후보 최근접역까지 **소요초·환승수**
- 환승수 = 최단경로상 **TRANSFER 엣지 통과 수**
- **투표 시작 시 1회 계산 → meeting_travel_burden DB 스냅샷** (Cloud Run 다중 인스턴스 안전)
- 후보별 최장 이동자 식별(UI 강조용)

## 이동 경로 스냅샷 ⭐ (2026-06-25 추가)
- 이동부담 계산과 **동일한 다익스트라 1회**로 **출발역→도착역 경로**도 함께 산출(prev 추적 + 경로복원).
- 경로 = `[{stationId, latitude, longitude}, ...]` **출발지부터 목적지까지 순서 리스트**.
- 저장 = `meeting_travel_burden.station_path` **JSONB 단일 컬럼**(반정규화). 별도 경로 테이블 금지(행 폭증 회피).
- 좌표는 `subway_station` 기준 배치 조회로 채움.
- 도달 불가 시 경로 = **빈 리스트** (seconds는 기존대로 무한대 처리).
- 노출: **친구들 거리보기 API에만** 경로 포함. 투표 현황(getVoteStatus)은 요약만 유지(경로 미포함).

## 친구들 거리보기 응답 ⭐ (2026-06-25 보강)
- 멤버 기준 = 해당 모임 **활성 참여자(ABSENT 제외) 전원**(요청자 본인 포함).
- burden 스냅샷 없는 멤버도 포함 → `seconds`/`transfers`=null, `path`=[].
- 멤버별 제공: 닉네임, **출발지 이름(departureName)**, **본인 여부(isMe)**, 소요시간/환승, 경로, 최장이동자 플래그.
- 출발지 이름 = 참여자 좌표를 멤버 `DeparturePlace`와 매칭(placeName→label), 없으면 기본 출발지, 그래도 없으면 null.
- `isLongest` = **소요시간 보유 멤버 중** 최대값에만 true.
- 신규 계산 없음(스냅샷 + 멤버/출발지 조회만). 스키마 변경 없음.
