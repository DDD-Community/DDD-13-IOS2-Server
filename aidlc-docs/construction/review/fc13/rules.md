# 비즈니스 규칙 — FC-13 장소 자동 확정

> 2026-06-24 갱신 (mvp3-1 갭). ⭐ 변경점.

## 트리거 ⭐
- 전원 투표완료 OR 투표 마감일 도래(스케줄러) OR **호스트 수동 확정**

## 순위 비교자 (공통) ⭐
> 1위 선정·1~3위 산출·수동확정이 **단일 Comparator** 공유(결정적).
1. **득표 수 최다**
2. 동점 → **모임원 전체 이동시간 합산 최소** (meeting_travel_burden seconds 합)
3. 동점 → **환승 횟수 합산 최소** (transfers 합)
4. 동점 → **그 장소를 최초로 담은 시각(min picked_at) 가장 빠른** 장소 ⭐ (기존 미정렬 버그 수정)
- 이동부담 스냅샷 없을 때(그래프 미로드): 2·3은 동일값 → 4로 귀결

## 1~3위 산출 ⭐
- 확정 시점 위 비교자로 1~3위 산출. 후보 < 3이면 후보 수만큼.
- 결과 응답 각 후보에 `rank` 부여. (별도 rank 테이블 없이 조회 시 계산)

## 전원 기권
- 전원 미투표 → 전원 0표 동점 → 4순위(최초 담은 시각)로 1위 확정

## 확정 후
- locationStatus → CONFIRMED
- 확정 장소 정보(장소명, 주소 등) meeting_confirmed_place 에 고정 저장
