# 비즈니스 규칙 — FC-4 그룹 & 첫 모임 생성

## 생성 규칙

- 모임 이름과 테마 태그를 입력하면 **그룹 + 모임 + 호스트 멤버십이 동시에 생성**된다. 셋 중 하나라도 실패하면 전부 취소된다.
- 그룹명과 모임명은 **입력한 이름 하나를 그대로 각각 저장**한다. (별도 입력 없음)
- 그룹을 만든 사람은 **자동으로 호스트**가 되며 참석여부 초기값은 "참여"다.
- 새로 만들어진 모임의 장소 상태와 날짜 투표 상태는 모두 **"선정 전"**으로 시작한다.

## 인가 규칙

- **로그인한 사용자만** 그룹을 만들 수 있다. (미로그인 시 401)

## 제약사항

| 항목 | 제약 | 위반 시 |
|---|---|---|
| 이름 길이 | 1자 이상, 30자 이하 | HTTP 400 |
| 테마 태그 | 8개 중 하나 필수 선택 | HTTP 400 |
| 그룹 최대 구성원 | 20명 | 초대 시점에 검증 (생성 시는 해당 없음) |

## 테마 태그 선택지
