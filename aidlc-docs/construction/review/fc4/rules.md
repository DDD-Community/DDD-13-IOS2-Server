# 비즈니스 규칙 — FC-4 그룹 & 첫 모임 생성

## 생성 규칙

- 모임 이름과 테마 태그를 입력하면 **그룹 + 모임 + 호스트 멤버십이 동시에 생성**된다. 셋 중 하나라도 실패하면 전부 취소된다.
- 그룹명과 모임명은 **입력한 이름 하나를 그대로 각각 저장**한다. (별도 입력 없음)
- 그룹을 만든 사람은 **자동으로 호스트**가 되며 참석여부 초기값은 "참여"다.
- 새로 만들어진 모임의 장소 상태와 날짜 투표 상태는 모두 **"선정 전"**으로 시작한다.
- **[FC-8 확장]** 생성 시 **장소 추천용 소프트 옵션**(`categoryLabels[]`, `vibes[]`)을 함께 입력받아 **모임(meeting)에 저장**한다. (그룹 테이블엔 저장 안 함, 첫 모임에 전달)
  - 다음 모임 생성에서도 동일 입력. `themeTagCode`(테마)는 추천의 **목적(occasion)** 최우선 신호로 사용.

## 인가 규칙

- **로그인한 사용자만** 그룹을 만들 수 있다. (미로그인 시 401)

## 제약사항

| 항목 | 제약 | 위반 시 |
|---|---|---|
| 이름 길이 | 1자 이상, 30자 이하 | HTTP 400 |
| 테마 태그 | 8개 중 하나 필수 선택 | HTTP 400 |
| categoryLabels | 고정 11종 내 값(배열, 선택) | HTTP 400 |
| vibes | place.vibe 표준목록 내 값(배열, 선택) | 느슨 검증 |
| 그룹 최대 구성원 | 20명 | 초대 시점에 검증 (생성 시는 해당 없음) |

## 테마 태그 선택지

비즈니스 / 친목 / 가족모임 / 회식 / 간단한 식사 / 스터디 / 생일파티 / 청첩장 모임

## [FC-8 확장] 소프트 옵션 선택지
- **categoryLabels**: 한식 / 중식 / 일식 / 양식 / 카페 / 디저트 / 주점 / 분식 / 아시아음식 / 뷔페 / 기타
- **vibes**: `place.vibe` 의 표준 분위기 태그 (`GET /api/v1/places/options` 로 제공)
