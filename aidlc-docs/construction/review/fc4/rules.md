# 비즈니스 규칙 — FC-4 그룹 & 첫 모임 생성

## 생성 규칙

- 모임 이름과 테마 태그를 입력하면 **그룹 + 모임 + 호스트 멤버십이 동시에 생성**된다. 셋 중 하나라도 실패하면 전부 취소된다.
- 그룹명과 모임명은 **입력한 이름 하나를 그대로 각각 저장**한다. (별도 입력 없음)
- 그룹을 만든 사람은 **자동으로 호스트**가 되며 참석여부 초기값은 "참여"다.
- 새로 만들어진 모임의 장소 상태와 날짜 투표 상태는 모두 **"선정 전"**으로 시작한다.
- **[FC-8 확장]** 생성 시 **장소 추천용 옵션**(`categoryLabels[]`, `vibes[]` = SOFT 선호, `reservable`/`parking` = HARD 필터)을 함께 입력받아 **모임(meeting)에 저장**한다. (그룹 테이블엔 저장 안 함, 첫 모임에 전달)
  - 다음 모임 생성에서도 동일 입력. `themeTagCode`(테마)는 추천의 **목적(occasion)** 최우선 신호로 사용.
  - `reservable`/`parking`은 **FC-8 `location/start` 시점에 다시 입력받지 않고, 생성 시 저장된 값을 그대로 사용**한다. NULL=필터 없음(둘 다 포함).

## 인가 규칙

- **로그인한 사용자만** 그룹을 만들 수 있다. (미로그인 시 401)

## 제약사항

| 항목 | 제약 | 위반 시 |
|---|---|---|
| 이름 길이 | 1자 이상, 30자 이하 | HTTP 400 |
| 테마 태그 | theme_tag 중 하나 필수 선택(현재 15종) | HTTP 400 |
| categoryLabels | 고정 11종 내 값(배열, 선택) | HTTP 400 |
| vibes | place.vibe 표준목록 내 값(배열, 선택) | 느슨 검증 |
| reservable | Boolean 또는 NULL(선택) | 검증 없음 |
| parking | Boolean 또는 NULL(선택) | 검증 없음 |
| 그룹 최대 구성원 | 20명 | 초대 시점에 검증 (생성 시는 해당 없음) |

## 테마 태그 선택지 (DB 관리 — 코드 재배포 없이 추가/변경 가능)

비즈니스 / 친구모임 / 가족모임 / 회식 / 간단한 식사 / 스터디 / 생일파티 / 청첩장 모임 / 데이트 / 단체모임 / 카페타임 / 점심식사 / 특별한날 / 기념일 / 2차

> **[FC-8 정합, V19]** place.occasion 실데이터(2299건 전수분석) 기준 정렬 — `친목` → `친구모임`으로 표시명 변경, `데이트`/`단체모임`/`카페타임`/`점심식사`/`특별한날`/`기념일`/`2차` 7종 추가. occasion 스코어링 매칭률 향상 목적
> **제외**: 혼밥/혼술 등 "혼자" 용도 occasion 값은 그룹모임 앱 취지와 안 맞아 테마태그로 추가하지 않음 (occasion 원본 데이터 정제는 별도 데이터 파이프라인 작업, 범위 외)

## [FC-8 확장] 소프트 옵션 선택지
- **categoryLabels**: 한식 / 중식 / 일식 / 양식 / 카페 / 디저트 / 주점 / 분식 / 아시아음식 / 뷔페 / 기타
- **vibes**: `place.vibe` 의 표준 분위기 태그 (`GET /api/v1/places/options` 로 제공)
