# DDD IOS2 - MVP1 PRD (미확정)

## 1. 개요

모임 구성원들이 날짜와 장소를 함께 정할 수 있는 모임 조율 서비스.
**그룹(Group)** 안에서 **모임(Meeting)** 을 반복 생성하는 2계층 구조.

---

## 2. 구조 정의

```
그룹 (Group)         ← 멤버십 유지, 호스트 권한 소속
  └── 모임 (Meeting) ← 날짜/장소 투표, 생명주기 독립
  └── 모임 (Meeting)
  └── ...
```

- 홈 화면 카드는 그룹당 **현재 진행 중인 모임** 1개의 상태를 표시
- 모임 이력 조회는 MVP2 이후 대응

---

## 3. 사용자 정의

| 역할 | 설명 |
| --- | --- |
| **호스트** | 그룹을 생성한 사람. 모임 생성, 날짜/장소 투표 시작·확정, 그룹 종료, 호스트 위임 권한 보유 |
| **구성원** | 초대 링크로 합류한 사람. 투표 참여 및 개인 정보 수정 가능 |

---

## 4. 기능 요구사항

### FC-4: 그룹 생성

**기존 그룹이 있는 경우**

- 홈 화면에 그룹 카드 목록이 보인다
- 카드에 표시되는 정보: 그룹명, 테마 태그, 현재 모임 장소(주소), 참석자 프로필 이미지 목록, 참석자 이름과 인원 수

**그룹이 없는 경우 (신규 생성)**

- 그룹 이름을 입력한다 (최대 20자)
- 테마 태그를 선택한다 (비즈니스 / 친목 / 가족모임 / 회식 / 간단한 식사 / 스터디 / 생일파티 / 청첩장 모임)
- 생성 완료 후 홈 탭 그룹 리스트에 해당 그룹이 노출된다 (최초엔 호스트 혼자)
- 그룹을 생성한 사람이 자동으로 호스트가 된다

**초대 공유**

- 호스트가 공유하기 버튼을 누르면 카카오톡으로 초대 링크가 전송된다 (iOS 담당)

---

### FC-5: 구성원 초대 및 합류

- 카카오톡 초대 링크를 통해 앱에 진입한다
- 로그인 후 해당 그룹에 자동으로 합류된다
- 합류된 그룹이 홈 탭 그룹 리스트에 노출된다

---

### FC-6: 그룹 리스트 (홈 화면)

- 홈 화면에는 탭 3개가 있다: **전체** / **진행 중** / **종료된**
- **진행 중** 탭은 다음 3가지로 분류된다
    - 장소 미확정
    - 장소 선정 중
    - 장소 확정
- **종료된** 탭에는 종료된 그룹 카드가 표시된다
- **전체** 탭은 진행 중 + 종료된 그룹을 모두 표시한다
- 카드를 클릭하면 그룹 상세 화면으로 이동한다
- 본인이 속한 그룹만 조회된다

---

### FC-7: 그룹 상세 (현재 모임 기준)

**표시 정보**

- 그룹명, 테마 태그, 장소 선정 상태(선정 전 / 선정 중 / 선정 완료)
- 참여인원 목록: 프로필 이미지, 이름, 출발지, 참석여부(참석 / 늦참 / 이동중 / 불참)
- 내 정보: 프로필 이미지, 이름, 참석여부 뱃지, 출발지

**날짜 투표 플로우** (장소 선정 전 상태에서 호스트가 "장소 정하러 가기" 버튼 클릭 시 시작)

호스트는 날짜 선택 방식을 먼저 고른다.

**방식 A - 호스트 단독 선택**

| 단계 | 행위자 | 내용 |
| --- | --- | --- |
| 1. 날짜 선택 | 호스트 | 달력에서 날짜 1개 선택 |
| 2. 날짜 확정 | 시스템 자동 | 투표 없이 즉시 확정, 구성원 전체에 확정 알림 발송 |
| 3. 다음 단계 | 시스템 자동 | 장소 선정 플로우로 진입 (MVP2) |

**방식 B - 투표**

| 단계 | 행위자 | 내용 |
| --- | --- | --- |
| 1. 투표 시작 | 호스트 | 달력에서 날짜 후보 1~10개 선택, 투표 기간 설정(1일 / 3일 / 7일), 저장 즉시 투표 시작, 구성원 전체에 푸시 알림 발송 |
| 2. 투표 참여 | 구성원 | 후보 날짜 중 가능한 날짜 복수 선택, 마감일까지 진행 |
| 3. 실시간 현황 | 구성원 | 날짜별 투표자 프로필 이미지와 투표 수 확인, 득표 순으로 정렬 |
| 4. 투표 마감 | 시스템 자동 | 마감일 도래 시 투표 종료, 호스트에게 날짜 확정 요청 알림 발송 |
| 5. 날짜 확정 | 호스트, 시스템 자동 | 호스트가 확정하거나 마감일에 1위 날짜 자동 확정, 구성원 전체에 확정 알림 발송 |
| 6. 다음 단계 | 시스템 자동 | 장소 선정 플로우로 진입 (MVP2) |

---

### FC-7-1: 내 정보 수정 (그룹 상세 내)

- 참석여부 뱃지를 변경할 수 있다 (참석 / 늦참 / 이동중 / 불참)
- 출발지를 수정하거나 추가할 수 있다
    - 출발지 변경 버튼 클릭 시 모달이 표시된다
    - 모달에는 현재 등록된 출발지 목록과 [수정하기] [출발지 추가하기] 버튼이 있다
    - 수정하기 또는 추가하기를 누르면 장소 검색 창이 열리고, 선택 즉시 반영된다
    - 출발지는 최대 3개까지 등록 가능하다
- 본인 정보만 수정할 수 있다

---

### FC-8: 그룹 생명주기 관리

**모임 종료**

- 모임 날짜가 지나면 시스템이 자동으로 해당 모임을 종료 처리한다

**그룹 종료**

- 호스트만 그룹 종료 버튼을 누를 수 있다
- 종료된 그룹은 홈 화면 "종료된" 탭으로 이동한다

**새 모임 시작 (재사용)**

- 기존 그룹에서 호스트가 새 모임을 시작할 수 있다
- 멤버십(구성원 목록)은 그대로 유지된다

**호스트 탈퇴**

| 경우 | 처리 |
| --- | --- |
| 호스트가 직접 위임 후 나가기 | 지정한 구성원이 호스트 승계 |
| 호스트가 위임 없이 나가기 | 시스템이 남은 구성원 중 랜덤 배정 |

---

## 5. 비기능 요구사항

- 날짜 투표 현황은 실시간(또는 준실시간)으로 반영된다
- 투표 마감, 날짜 확정 시 푸시 알림이 발송된다
