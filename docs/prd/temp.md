# FC-9 장소 후보 리스트 탐색

## 문서 개요

| 항목 | 내용 |
| --- | --- |
| 기능 코드 | FC-9 |
| 기능명 | 장소 후보 리스트 탐색 |
| 목적 | 날짜 확정 후 모임원 전체가 추천 장소 리스트를 탐색하고, 각자 마음에 드는 장소를 투표 후보로 담는 플로우. 모임원 전체가 담기를 완료하거나 마감일(날짜 확정 후 +3일) 도래 시 자동으로 투표 플로우로 전환. |
| 범위 제외 | 장소 검색 기능 제외 / 지도 뷰 전환 제외 / 호스트 단독 장소 선정 기능 제외 |

## 단계별 기능 명세

### 9-1. 장소 후보 리스트 뷰

- 없는 데이터는 미노출

| 항목 | 명세 |
| --- | --- |
| 모임원 담기 현황 | 화면 내 모임원별 장소 담기 완료 여부 표시. 완료한 모임원 프로필은 체크 이미지로 변경. |
| 상단 정보 | 현재 선택된 지역(역명) 표시
  • 각 지역 선택 시, 해당 지역에 해당되는 장소 후보 리스트 노출 |
| 카테고리 | 카테고리별 추천 장소 확인 가능, 장소 후보에 없는 카테고리는 미노출
  • 카테고리: 카페 / 디저트 / 한식 / 중식 / 일식 / 양식 / 분식 / 아시아 음식 / 뷔페 / 주점 / 기타 |
| 필터 | 예약 가능 / 주차 가능 필터 노출
  • 필터 선택 시 해제 전까지 카테고리 이동하며 탐색해도 그대로 적용됨 |
| 카드 정렬 기준 | 추천 알고리즘 스코어 내림차순 |
| 카드 구성 요소 | 상호명, 카테고리, 도로명 주소, 분위기 태그(최대 3개), 유저 출발지 기준 거리, [+] 버튼
  • [+]버튼 터치 시 해당 장소가 장소 투표 후보로 추가됨, 재탭 시 취소 |
| 하단 CTA | 후보 1개 이상 추가된 상태에서만 '투표 시작하기' 활성화  |
| 로딩 처리 | 스켈레톤 UI 표시 |

### 9-2. 장소 투표 후보 전환 조건

| 조건 | 처리 방식 |
| --- | --- |
| 모임원 전체가 장소 담기 완료 시 | 즉시 투표 플로우로 전환. 구성원 전체에 '모든 모임원이 장소 후보를 선정했어요. 투표가 시작됩니다!' 알림 발송. |
| 장소 담기 마감일 도래 시  | 미완료 모임원 있어도 자동으로 투표 플로우로 전환. 구성원 전체에 '장소 후보 선정이 완료됐어요. 투표가 시작됩니다!' 알림 발송. |
| 호스트가 '투표 생성하기' 버튼 탭 시 | 마감일 전이어도 즉시 투표 플로우로 전환. 구성원 전체에 '장소 후보 선정이 완료됐어요. 투표가 시작됩니다!' 알림 발송. |
| 마감일 도래 후 접근 시 | 장소 담기 불가. '장소 후보 선정이 마감되었습니다' 안내 후 투표 화면으로 이동. |

### 9-3. 장소 상세

각 장소 후보 터치 시 노출되는 상세페이지. 지도 위 바텀시트 형태로 노출

| 항목 | 명세 |
| --- | --- |
| 진입 방식 | 지도 위 장소 핀 탭 or 각 장소 후보 터치 |
| 지도 영역 | 상단 지도에 추천 장소 핀 목록 표시. 카테고리별 아이콘·색상으로 구분. |
| 핀 탭 시 | 해당 장소 상세 정보가 하단 시트 형태로 노출. 지도는 유지된 상태로 하단에 상세 오버레이. |
| 함께 담기 버튼 | 지도 위 우측 하단에 '함께 담기 N' 버튼 표시. N은 투표 후보를 추가한 모임원 수 |
| 거리 및 카테고리 | 유저 출발지 기준 거리 + 카테고리 텍스트 표시. |
| 영업시간 | 월 휴무 여부, 평일/주말 영업시간 표시. |
| 주소 | 도로명 주소 + 지번 주소. 각 주소 우측 복사 아이콘 제공. |
| 좌측 CTA | '장소담기'. 탭 시 해당 장소를 장소 투표 후보로 추가. 이미 담은 장소는 '담기 취소'로 변경. |
| 우측 CTA | '자세히보기'. 탭 시 네이버지도의 해당 장소 상세페이지로 이동 (nmap://place?id={place_id}) |

### 9-4. 장소 함께 담기

장소 후보를 담은 모임원별 현황 확인 가능한 페이지

| 항목 | 명세 |
| --- | --- |
| 화면 타이틀 | '장소 함께 담기' |
| 모임원 담기 현황 | 화면 상단에 모임원 프로필 이미지 목록 표시. 담기 완료한 모임원은 프로필 하단에 체크 아이콘 표시. 미완료 모임원은 체크 없음. |
| 카테고리 탭 | 전체 / 한식 / 카페 등 카테고리별 탭 필터. 장소 후보에 없는 카테고리는 미노출. |
| 카드 구성 요소 | 카테고리 아이콘, 상호명, 거리, 주소(서울 강남구 역삼동), 분위기 태그(최대 3개), [+] 버튼 |
| 마감 임박 섹션 | 마감 1일 전: '장소 선정일이 1일 남았어요' 빨간색 토스트 노출. X 버튼으로 닫기 가능. |
| 진행 중 섹션 | 진행 중 상태: '장소 선정은 3일동안 진행되요' 초록색 토스트 노출. X 버튼으로 닫기 가능. |
| 투표 생성하기 버튼 | 호스트에게만 노출. 하단 고정. |
| 투표 생성하기 비활성화 조건 | 아무도 장소를 담지 않은 상태 |
| 투표 생성하기 활성화 조건 | 모임원 중 1명 이상 장소 담기 완료 시 (호스트 포함 누구든) |
| 투표 생성하기 탭 시 | 마감일 전이어도 즉시 투표 플로우로 전환. 구성원 전체에 알림 발송. |
| 로딩 처리 | 스켈레톤 UI 표시 |
