## 단계별 기능 명세

### 12-1. 장소 투표 리스트

투표가 시작된 후 구성원이 보는 투표 화면

| 항목 | 명세 |
| --- | --- |
| 화면 구성 | 모임 상세페이지 상단 영역에 노출 |
| 투표 후보 구성 | 카테고리 아이콘, 상호명, 도로명 주소, 자세히 버튼 |
| 투표 후보 정렬 기준 | 투표 전
  • 상호명 가나다순
투표 후
  • 득표수 높은순 |
| 투표 상태 표시 | 투표 전
  • 투표 선택지 + 투표하기 버튼 노출
투표 후
  • 현재까지의 투표 현황 반영된 결과 화면 + 다시 투표하기 버튼 노출
  • 호스트의 경우 다시 투표하기 버튼과 함께 확정하기 버튼 노출 |
| 로딩 처리 | 실시간 투표 수 변경 시 카드 단위로 부분 업데이트. 전체 리로드 지양 |

### 12-1.1 장소 상세 바텀시트

**기본 장소 상세 정보 바텀시트**

| 항목 | 명세 |
| --- | --- |
| 진입 방식 | 지도 위 장소 핀 탭 or 각 장소 후보 터치 |
| 지도 영역 | 상단 지도에 추천 장소 핀 목록 표시. 카테고리별 아이콘·색상으로 구분. |
| 핀 탭 시 | 해당 장소 상세 정보가 하단 시트 형태로 노출. 지도는 유지된 상태로 하단에 상세 오버레이. |
| 함께 담기 버튼 | 지도 위 우측 하단에 '함께 담기 N' 버튼 표시. N은 투표 후보를 추가한 모임원 수 |
| 거리 및 카테고리 | 유저 출발지 기준 거리 + 카테고리 텍스트 표시. |
| 영업시간 | 월 휴무 여부, 평일/주말 영업시간 표시. |
| 주소 | 도로명 주소 + 지번 주소. 각 주소 우측 복사 아이콘 제공. |

> **데이터 소스 (FC-8 보강, V32)**: 기본 상세 필드는 `GET /api/v1/places?ids=` 응답으로 제공.
> 영업시간=`businessHours`, 휴무=`holiday`, 도로명=`roadAddress`, 지번=`address`, 네이버링크=`naverUrl`(딥링크는 프론트가 `placeId`로 조립).
> 거리·'함께 담기 N'은 상세 API 스코프 제외(각각 거리보기/담기현황 책임).

**'친구들 거리보기' 버튼 탭 시 노출되는 바텀시트.**

- **지도 영역**

| 항목 | 명세 |
| --- | --- |
| 닫기 | 우측 상단 X 버튼. 탭 시 바텀시트 닫힘. |
| 구성원 위치 표시 | 각 구성원의 출발지 위치가 프로필 이미지로 지도 위에 표시. |
| 동선 표시 | 각 구성원 출발지 → 장소까지의 이동 경로를 점선으로 표시. 구성원별 색상 구분. |
| 이동 정보 말풍선 | 각 구성원 프로필 이미지 상단에 '환승 N회 N시간 N분' 말풍선 표시. |

**하단 정보 영역**

| 항목 | 명세 |
| --- | --- |
| 상호명 | Bold 텍스트. |
| 거리 및 카테고리 | 상호명 하단에 거리(km) + 카테고리 텍스트 표시. |
| 섹션 타이틀 | '모임원들의 소요 시간' |
| 내 정보 | 리스트 최상단에 본인(나) 먼저 표시. 프로필 이미지 + 이름 + '나' 뱃지 + 출발지 + 환승 횟수·이동 시간. |
| 팀원 정보 | '팀원 N명' 섹션으로 구분. 프로필 이미지 + 이름 + 출발지 + 환승 횟수·이동 시간. 스크롤 가능. |
| 이동 시간 강조 | 이동 시간이 가장 긴 구성원은 빨간색으로 강조 표시. |
| 출발지 미등록 구성원 | 이동 시간 정보 미노출. |

**(공통) 바텀시트 하단 CTA**

| 항목 | 명세 |
| --- | --- |
| 좌측 버튼 | '자세히보기'. 탭 시 외부 지도 앱으로 연결. 네이버지도: nmap://place?id={place_id} |
| 우측 버튼 | '투표하기'. 탭 시 해당 장소를 장소 투표 선택된 것으로 처리(12.2의 라) . 이미 투표한 장소는 '투표 취소'로 변경.
 |

### 12-2. 투표 방식

후보 장소 중 라디오 버튼 선택해서 투표하는 방식

| 항목 | 명세 |
| --- | --- |
| 투표 선택 | 자세히 버튼 제외 리스트 영역 터치 시 선택됨 |
| 다중 장소 투표 | 1인이 여러 장소에 각각 좋아요 가능. 단, 1인 최대 투표 가능 장소 수는 후보 수의 50% 이하로 제한 (예: 후보 6개 → 최대 3개).
 |
| 재투표 | 투표 후 다시 투표하기 버튼 터치 시 재투표 가능 |
| 리액션 익명 처리 | 익명 처리. 누가 어느 장소에 투표했는지는 구성원 및 호스트 모두에게 비공개. 호스트에게는 투표 완료 여부(완료/미완료 구분)만 공개. |
| 서버 처리 방식 | 투표 탭 즉시 API 호출. 성공 응답 후 UI 업데이트. 실패 시 이전 상태로 롤백 + 에러 토스트 표시. |

### 12-3. 투표 현황

| 항목 | 명세 |
| --- | --- |
| 투표 현황 갱신 | 페이지 진입 시, 유저가 투표 완료 시(투표하기 버튼 터치 시) |
| 집계 항목 | 장소별 득표수, 전체 투표 참여 인원(N/N명) |
| 미투표 구성원 표시 | 호스트 화면에서만 미완료 구성원 수 확인 가능. 구성원 화면에는 총 참여율(N/N)만 표시. |
| 투표 인원 현황 | 카드 상단에 {투표 완료한 인원} / {모임원 수} 표기 |

### 12-4. 미응답 구성원 리마인드

투표 미완료 구성원에게 리마인드 알림을 발송하는 기능.

| 항목 | 명세 |
| --- | --- |
| 발송 주체 | 시스템 자동 발송 |
| 자동 발송 시점 | 투표 마감 24시간 전 1회. 마감이 24시간 이내로 설정된 경우 마감 1시간 전 1회로 대체. |
| 알림 내용 | "[모임명] 투표 마감이 얼마 남지 않았어요. 아직 투표하지 않으셨나요?" |
| 알림 탭 액션 | 해당 모임의 투표 화면으로 딥링크 |
| 중복 발송 방지 | 리마인드 발송 시점 이전에 투표 완료한 구성원에게는 발송 안 함 |

### 12-5. 투표 기간 만료 처리

마감 시간 도달 시 미응답 구성원이 있어도 현재까지 집계 기준으로 순위 생성.

| 항목 | 명세 |
| --- | --- |
| 마감 기준 | 호스트가 확정 or 모든 모임원이 투표 완료 시 or 마감일 도래했을 경우 자동으로 투표 종료 |
| 처리 | 현재 집계 기준 순위 자동 생성 + 투표 여부와 무관하게 투표 완료 UI 노출 |
| 알림 | 전체 구성원에게 투표 기간 종료 푸시 알림 발송 |
| 미투표 구성원 처리 | 기권 처리. 현재까지 집계된 결과만으로 순위 산출. |

---

### 12-6. 자동 순위 생성 및 FC-13 진입

집계 완료 후 자동으로 1~3위 순위를 산출하고 FC-13으로 연결.

| 항목 | 명세 |
| --- | --- |
| 순위 산출 기준 | 좋아요 수 기준 내림차순 1~3위 |
| 동점 처리 | 1순위: 구성원 전체 이동 시간 합산이 낮은 장소 우선. 2순위: 환승 횟수 합산이 적은 장소 우선. 3순위: 후보 등록 순서 기준(먼저 등록된 장소) 우선. |
| 순위 배지 | 1위·2위·3위 배지를 해당 카드에 자동 표시 |
| 4위 이하 장소 | 1~3위 강조, 나머지는 하단에 축소 표시 |
| 전원 투표 완료 시 (Case A) | 즉시 순위 생성 + 호스트에게 장소 확정 요청 알림 발송 → FC-13 진입 |
| 투표 기간 만료 시 (Case B) | 마감 시점 집계 기준 순위 생성 + 전체 구성원 알림 발송 → FC-13 진입 |

## 예외 처리 및 엣지 케이스

| 케이스 | 처리 방식 |
| --- | --- |
| 전원 미투표 상태로 기간 만료 | 좋아요 수 0 전체 동점 → 등록 순서 기준 순위 생성. 호스트 화면에 "투표 참여가 없었어요. 등록 순서로 순위를 정했어요." 안내 표시. |

| 네트워크 오류로 투표 API 실패 | 이전 상태 유지 + "투표에 실패했어요. 다시 시도해주세요." 에러 토스트 표시 |
| 후보 장소가 1개인 경우 | 후보 리스트업 단계에서 최소 2개 이상 후보 등록 조건 적용. 1개인 상태에서는 투표 시작 버튼 비활성화. |
| 최대 투표 수 초과 시도 | 상한 초과 시 좋아요 버튼 비활성화 + "최대 N개 장소까지 투표할 수 있어요." 토스트 표시 |

## 단계별 기능 명세

### 13-1. 자동 확정 처리

투표 종료 시점에 시스템이 자동으로 처리하는 단계.

| 항목 | 명세 |
| --- | --- |
| 확정 기준 | 좋아요 수 1위 장소 자동 확정. 동점 처리는 FC-12 12-6 동점 처리 기준 동일 적용. |
| 확정 데이터 저장 | 확정 장소명, 주소, 확정 일시, 모임 ID, 확정 방식(자동)을 DB에 저장 |
| 히스토리 저장 | 확정된 장소를 H3 기반 히스토리에 자동 저장. 정기모임 재사용 기반 데이터로 활용. |
| 모임 상태 변경 | 모임 상태를 '장소 확정 완료'로 업데이트. 스텝 인디케이터 전체 완료 처리. |
| 알림 발송 | 확정 즉시 전체 구성원에게 푸시 알림 발송 |
| 저장 시점 | 투표 종료 이벤트 발생 후 서버 처리 완료 시점에 저장. 실패 시 재시도 3회 후 운영팀 알림. |

### 13-2. 투표 결과 및 확정 완료 화면

- 확정 장소와 함께 투표 순위 결과 1~3위를 함께 노출.
- 확정된 장소 카드의 [자세히 보기] 터치 시 네이버맵의 해당 장소 상세페이지 열림

| 항목 | 명세 |
| --- | --- |
| 화면 구성 | 상단: '장소 확정 완료' 상태 배지. 모임명, 확정 장소명, 날짜·시간. 하단: 투표 순위 결과 1~3위 카드 리스트. |
| 확정 장소 강조 | 1위(확정) 장소는 상단에 별도 강조 영역으로 표시. 확정 배지 노출. |
| 투표 순위 결과 | 1~3위 장소 카드 노출. 카드 구성: 순위 배지, 장소명, 썸네일, 좋아요 수, 구성원 평균 이동 시간, 환승 횟수. |
| 순위 노출 기준 | 후보 수가 3개 미만인 경우 후보 수만큼만 노출 (예: 후보 2개 → 1~2위만 표시). |
| 4위 이하 장소 | 노출 안 함. |
| 장소 정보 | 확정 장소 기준: 장소명, 주소, 영업시간, 분위기 태그 |
| 구성원 확인 상태 | 구성원 목록과 각자의 확인 여부 표시. 확인: '참석 예정' 배지. 미확인: '확인 전' 상태. |
| 이동 정보 | 확정 장소 기준 구성원별 환승 횟수·이동 시간 리스트 표시 |
| 지도 보기 | '지도로 보기' 버튼 탭 시 네이버지도 앱으로 확정 장소 위치 전달. 단, 연동 방식(플레이스 ID 딥링크 vs 좌표 기반 딥링크)은 FC-9 장소 데이터 소스 확인 후 확정 필요. |
| 예약 가능 장소 안내 | 해당 장소가 예약 가능한 경우 '예약 사이트로 이동하기' CTA 버튼 노출. 외부 링크 연동. |
| 닫기 | '닫기' 버튼 탭 시 모임 상세 화면으로 복귀 |
